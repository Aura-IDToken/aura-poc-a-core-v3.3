# GAP-001 — Implementation Gap Report

**Document ID:** GAP-001  
**Repository:** aura-poc-a-core (v3.3)  
**Status:** Updated after CORE-005  
**Date:** 2026-07-24  

---

## 1. Purpose

This document tracks implementation gaps relative to the current repository state.
It has been synchronized after CORE-005.

Historical findings that claimed policy logic still lived in `core/evaluator.py` were resolved by CORE-005.
Historical findings that described the active Layer 0 evaluator path as float-based were superseded by the current integer-scaled implementation.

---

## 2. Current implementation snapshot

| Area | Current state |
|------|---------------|
| Layer 0 measurement | `core.evaluator.PoCAEvaluator` performs integer-scaled measurement only |
| Layer 1 audit | `audit.merkle` and `audit.verify` provide Merkle proof construction and verification |
| Layer 2 policy | `compliance.policy` owns target validation, halt logic, and policy penalties |
| Layer 2 orchestration | `compliance.evaluator_wrapper.evaluate_with_policy()` is the preferred policy-aware entry point |
| Compatibility wrappers | `core.policy` and `core.consistency` remain deprecated wrappers in v3.3 |

---

## 3. Resolved items relevant to CORE-005

| Gap | Status | Notes |
|-----|--------|-------|
| CORE-003 — Remove float from `core/evaluator.py` | ✅ Resolved | Active evaluator path is integer-scaled |
| CORE-004 — Remove float from `core/consistency.py` | ✅ Resolved for active path | `core/consistency.py` is now a deprecated wrapper to `compliance.consistency` |
| CORE-005 — Move policy logic out of `core/` | ✅ Resolved | Policy logic now lives in `compliance/` |

### CORE-005 acceptance status

- No compliance status strings are returned by `core.evaluator.PoCAEvaluator.evaluate()`
- Policy-aware flows use `compliance.evaluator_wrapper.evaluate_with_policy()`
- Repository examples should prefer `compliance.policy` and `compliance.consistency` imports

## 5. Documentation sync notes

The repository documentation should now reflect these rules:

- use `PoCAEvaluator` instead of nonexistent `evaluate()` or `calculate_ari()` functions
- use `compliance.policy` and `compliance.consistency` as preferred imports
- describe `core.policy` and `core.consistency` as deprecated wrappers
- describe float usage as offline-only in `core/offline_normalizer.py`
- describe Layer 0 as measurement only
